# Molia 0.2.0

0.1.0 之后的一个稳定版本。这一轮的力气主要花在「本地优先」：把本地曲库做成能扫、能整理、
能查的样子，补上歌单与统计的进出通道，同时让取链和播放失败恢复更可靠。

## 新增

### 音源与播放

- **汽水音乐**成为第七个内置渠道：搜索、歌手页、专辑、评论、歌单与逐字歌词；取链由 LX
  音源脚本提供（会员曲目的匿名接口只给 30 秒试听流）。
- **取链加固**：内置传输统一重试预算与结果缓存；单次取链超时只失败该请求，不再拖垮整条
  队列；脚本引擎连续超时熔断后自动冷却恢复，网络变化时重试。
- **播放失败自动恢复**：失效缓存 → 原地重取链并保留播放进度 → 同一曲目整首重试一次 →
  仍然失败才换源。
- 播放淡变、暂停淡出、睡眠淡出与智能随机（随机轮次可预期，切换模式或切歌重抽）。
- 手机横屏改为专门的紧凑布局，不再挤压播放控件。

### 资料库

- **本地音乐**：音乐文件夹扫描、缺文件探测、专辑 / 歌手聚合、智能列表、重复版本展开，
  以及「只改标题」的标签编辑器。
- **歌单**：详情页、分享海报、M3U8 导入导出，当前队列可存为列表。
- 收藏 / 列表 / 本地曲目共用一套列表元数据与分组，宽屏恢复歌曲表格列；动图封面统一归一化
  为 WebP 后随同步发送。
- 多选支持长按范围选择；歌词选择支持全选与范围选择，取消原来的 15 行上限。

### 统计与诊断

- 听歌统计与年度报告：曲目 / 歌手 / 平台榜单、日历与作息热力图，支持分享与保存图片。
- 诊断页：轮转日志、失败记录、渠道检查、取链会话指标与一键导出诊断文件。

### 可选在线服务

- **听歌同步**：ListenBrainz / Last.fm，默认关闭；只在你开启后发送歌名、歌手、专辑、时长
  与开始播放时间。
- **AI 推歌**：生成进度收敛为一条进度，生成期间可以继续播放旧列表；换一批 / 补一批 /
  历史收进顶栏。
- **跨设备同步**：新增海报样式与 AI 推荐历史两个类别，封面支持动图。

### 体验与桌面

- 首次启动四屏引导，随时可以跳过。
- 平板 / 折叠屏宽度档位：手机与桌面共用一套自适应布局，不再按设备类型分叉。
- 无障碍：主链路语义标签、键盘焦点顺序、200% 字号与跟随系统的减弱动效。
- 设置首屏按域重组成九张卡，目录子页合并，写入即时生效。
- 播放页与底栏收敛：进度排收进「更多」菜单，底栏不再堆叠重复入口。
- Windows：Win11 贴靠布局、虚拟桌面跟随、按虚拟桌面分组记忆窗口位置；系统退出请求先落盘
  再退出；最小窗口 480×400。
- Material 3 Expressive 细节：圆角统一到形状令牌、波浪页脚、滚动边缘渐隐、内容交叉淡化、
  歌单首屏骨架屏、下载任务行内进度。
- 托盘内存：暂停时释放播放器、切歌后补一次 trim。

## 修复

- 哔哩哔哩登录用户的字幕歌词在首帧后恢复，不再需要重开页面。
- 手机横屏、预测返回手势与页面横竖切换的布局回归。
- 封面回退到默认图、重复版本切换、本地标题刷新与缺文件入口的边界问题。
- 随机播放轮次证据、暂停淡出与睡眠淡出互相覆盖、取消后音量未复位。

## 升级说明

- 0.1.0 可以直接覆盖安装，曲库数据会自动迁移到新结构；迁移前会在数据目录留一份 `.bak`
  备份（仅供人工排查，不自动回滚）。
- **凭据改为存本机凭据库（明文 SQLite），不再依赖系统钥匙串。** 旧的系统钥匙串凭据不自动
  迁移，升级后需要重新登录哔哩哔哩、重新填写 AI Key、听歌同步 Token 与跨设备同步口令。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
- 0.2.0 与 0.2.0-beta.7 功能一致，测试版用户可以直接覆盖安装。

## 安装与升级

- **Android**：覆盖安装需要与已装版本使用同一签名（测试版与正式版同一签名）；优先选
  `arm64`，较老的 32 位设备选 `armv7`。应用内更新需要允许「安装未知应用」。
- **Windows**：安装器会创建开始菜单 / 桌面入口；便携版解压即用。
- **Linux**：托盘图标需要系统有 StatusNotifier 宿主（GNOME 需 AppIndicator 扩展），缺失时
  自动降级为无托盘。
- **iOS / macOS**：产物未签名 / 未公证；iOS 需自行签名侧载，macOS 首次打开可能需要在
  「系统设置 › 隐私与安全性」中放行。
- **更新渠道**：Android / Windows / Linux 支持应用内检查更新与安装；macOS 请从发布页手动
  下载覆盖。

## 校验

每个产物都附带 `SHA256SUMS.txt`，下载后可校验完整性：

```bash
sha256sum -c SHA256SUMS.txt
```

## 数据与隐私

- 收藏、列表、历史、统计保存在本机 SQLite。
- 各类凭据（AI Key、听歌同步 Token、B 站登录、跨设备同步口令）保存在本机凭据库；它是
  明文 SQLite，能读本机数据目录或备份文件的人也能读到，这是本版接受的本机取舍。
- AI 推歌与跨设备同步默认关闭，开启前会展示数据发送范围 / 信任说明。
- 跨设备同步的快照整体加密（AES-256-GCM），同步口令不会被明文上传。
- LX 音源脚本是第三方可执行代码：在隔离环境中运行，但脚本仍可发起网络请求，导入前请确认
  来源可信。
- 完整备份默认包含全部凭证与用户数据；备份文件本身是明文 JSON，请妥善保管。
