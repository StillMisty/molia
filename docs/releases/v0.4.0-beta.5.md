# Molia 0.4.0-beta.5

0.4.0-beta.4 之后的测试版：桌面拖拽窗口明显更顺，修掉收藏页切换合集后滚动条
拖不动、宽屏返回键被残留展开态吞掉，以及听歌同步补跑和统计窗口结算的问题。

## 改进

- **桌面窗口缩放更顺**：隐藏页不再参与布局与尺寸重建，窗口尺寸、DPR、断点变化
  也不会让隐藏页在后台重建；封面解码按 256/384/512/600 逻辑档位取档，拖动窗口
  不再每像素换一张解码图。同机 Linux profile 实测 build p50 5.80 → 3.38ms
  （−42%），仓库 resize 场景 jank 6 → 1。
- **内置渠道不再为查能力提前拉起脚本**：内置音源的原生搜索 / 取链 / 歌词走自带
  声明，纯脚本音源仍按需激活；每个传输实例的重试间隔也相互独立。

## 修复

- 收藏页切换合集后滚动条拖不动：列表重建后找回正确的滚动位置与手势绑定。
- 桌面 / 宽版式下残留的播放页展开态不再吞掉返回键与 Esc。
- 听歌同步：自动轮在途时的手动补跑会按请求合并成一轮，不再被压成只拉或窄范围；
  待发标记只在本轮真的传输成功时按类别清掉，零对端与失败轮不再误清。
- 听歌统计：加载失败或过期结果不再推进统计窗口，跨午夜与乱序返回不会把数据
  算进错误的时间段。
- 设备本地设置（音量、播放手感、引导标记）：损坏的 JSON 值自动回退，旧音量键
  整组兜底，多个实例并发写入改为串行，不再互相覆盖。

## 内部

- 音源能力统一经 SourceRouter 路由，内置传输由组合根构建后注入，发现端点缓存
  与单次预算行为保持不变。
- 听歌同步的排队、补跑合并与交付台账收进 SyncRoundQueue；收藏键 / 行 / 计数
  收进 FavoriteFact；设备本地偏好收进 DeviceSettings；壳层展示判定收进
  ShellPresentation；听歌统计新增纯 Dart 投影模块。
- 新增架构棘轮：设备本地设置直连 SharedPreferences 扫描、发现端点缓存直调扫描。

## 升级说明

- 测试版与 0.3.0 及各测试版使用同一签名，可直接覆盖安装；构建号单调递增，应用内
  更新能正常识别。设置 › 更新 › 更新渠道选「测试版」即可收到本版。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
