新增
· 桌面输出设备丢失（拔耳机 / 蓝牙断开 / DAC 掉电）时自动暂停，不再外放
· Windows 音量合成器显示 Molia，不再显示 JustAudioMediaKit
· macOS 菜单栏新增「播放」菜单：播放 / 暂停、上一首、下一首
· Linux 桌面入口支持按「音乐 / 播放器」搜索，通知归属应用

改进
· 打开 Molia 不再打断其他应用；暂停 20 秒、停止或退出后释放音频会话
· Android「与其他应用同时播放」真正混播：导航语音压低音乐并自动恢复

修复
· 中断结束后无法自动续播；冷启动释放会话误伤恢复播放；Windows 默认输出跟丢设备

注意
· 测试版与 0.3.0 使用同一签名，可直接覆盖安装；设置 › 更新选「测试版」渠道
