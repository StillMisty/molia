# Molia 0.5.0-beta.3

0.5.0 的第三个测试版：问题排查升级为诊断支持中心，应用与音源更新支持自动检查，
启动可恢复上次停留的页面，桌面窗口缩放更跟手，并升级可用的直接依赖。

## 新增

### 诊断支持中心

- **结论优先**：问题排查页首屏先给一句「现在能不能用、哪里需要处理」，并显示
  最近一次自检时间与上次是否异常退出。
- **分层自检**：按应用、音源、播放后端、存储与数据库、账号与同步五个域检查；
  音源检查沿用当前音质偏好，除搜索与取链外还会验证播放流首字节。
- **最近问题归并**：同一渠道、同一原因合并成一条，显示发生次数与最近时间，
  展开才看单次记录。
- **日志可查看**：新增日志子页，可直接查看与筛选，不再只能先导出文件。
- **报告出口**：支持预览、复制、保存与分享，附近标注隐私与大小提示；报告不含
  原始异常、URL、请求头或 Cookie。

### 自动检查更新

- 新增「启动时检查」「每日检查」两个独立开关（默认关闭）；开启后同时检查应用
  发布清单与声明了更新地址的 LX 音源。
- 发现应用或音源更新时弹一条合并提示，可直接进入「关于与更新」或音源管理页；
  手动检查仍只在设置页内展示结果。

### 其他

- **启动恢复上次一级页**：重新打开应用会回到上次停留的首页 / 搜索 / 资料库等
  一级页；可在设置里关闭。
- **桌面窗口缩放**：拖动缩放只在档位或阈值变化时通知，去掉逐像素整壳与整页重建，
  拖动更跟手。

## 依赖

- 升级 `nativeapi` / `nativeapi_flutter` 至 0.6.2、`sqlite3` 至 3.9.2、
  `tray_manager` 至 0.9.1，并刷新其余补丁版本。

## 注意

- 测试版与稳定版使用同一签名，可直接覆盖安装。
- 测试版走滚动 `beta` 更新清单，会先于稳定版收到后续 0.5.0 的改动。
