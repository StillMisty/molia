# Molia 0.4.0-beta.4

0.4.0-beta.3 之后的测试版：移动端播放器收起态与返回层级重写，统一成一条顶栏
播放条；另修复了收藏页把本地歌曲标成下载的问题。

## 改进

- **移动端只保留一条迷你播放器**：顶栏播放条（封面 + 歌名/作者 + 播放/暂停 +
  下一首 + 进度线）成为不在完整播放器时的唯一传输入口。播放页内的 72dp 迷你条
  随本次删除，收起高度归 0，歌词 / 队列 / 信息区拿到完整空间。
- **进入播放页总是展开**：从资料 / 发现、收藏、底栏或顶栏曲目区进入都是完整
  播放器，不再继承上一轮手动收起的迷你态；收起只能在播放页内主动触发。展开 /
  收起与顶栏↔播放页共用同一套封面飞行，落点不再互相打架。
- **返回层级更符合预期**：移动端资料 / 发现、收藏、播放页收起态按系统返回直接
  退出应用；播放页展开时第一次返回先收起，第二次才退出。桌面 Esc 优先收起打开
  的队列、其次收起播放器，不再被当成浏览器后退键。
- **新增「回到播放页时显示歌词」**：默认开、跟人走，入口在 设置 › 高级设置 ›
  播放细节；只在从其它一级页进入播放页时生效，播放页内部开二级页返回不会重置
  当前标签。
- **桌面品牌胶囊收口**：高度 40dp、内边距 12dp，长名称省略，窄窗只显示 LOGO。

## 修复

- 收藏页的本地歌曲行不再显示「已缓存」下载图标：本地文件本来就不是下载，图标
  会让人误以为点了会删歌。清除缓存入口仍在多选操作里。

## 内部

- 新增架构守卫：`lib/` 内除 `themed_app.dart` 外禁止 `MediaQuery.of` 整树订阅，
  改用 `sizeOf` / `paddingOf` / `devicePixelRatioOf` 等分面访问器，避免键盘与
  旋转导致整棵子树重建。
- 性能工具：帧场景支持 `--only` 筛选与请求场景校验，统计页可一条命令取
  timeline，headless 默认关闭 AT 桥；修正长场景被 5s 窗口切分时汇总低估的问题。
- 新增无设备 UI 预览脚本（`tool/agent/ui_preview.sh`），360 / 640 真实壳层与设置
  弹层截图不依赖模拟器；桌面品牌胶囊补独立组件测试。

## 升级说明

- 测试版与 0.3.0 及各测试版使用同一签名，可直接覆盖安装；构建号单调递增，应用内
  更新能正常识别。设置 › 更新 › 更新渠道选「测试版」即可收到本版。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
