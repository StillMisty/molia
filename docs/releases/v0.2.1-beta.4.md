# Molia 0.2.1-beta.4

0.2.1-beta.3 之后的第四个测试版，以修复为主：音频缓存写入与 Linux 系统媒体控制。

## 修复

### 音频缓存

- **同一缓存文件只允许一个写入者**：重复播放、自动连播或播放失败原地重取时，边播
  边缓存可能在同一个缓存文件上再起一份下载。两个下载各自写同一个 `.part`、完成时
  各自改名，结果目录里留下「完整文件 + 半成品」并存——既白占磁盘，也可能在先后
  完成时覆盖已经可用的缓存。现在同一缓存文件在任一时刻只有一个写入者：撞上在途
  写入时本次直接流播，不再并行写。
- 完整缓存已经落位时直接本地播放，不再创建缓存源，并清掉中断遗留的 `.part`
  半成品（beta.3 及更早版本留下的残留会在该曲下次播放时清掉，其余在下次启动清扫）。
- 后台字节预取对同一路径不再重复启动；播放侧已经接手同一文件时，预取不再改名覆盖。

### Linux

- 系统媒体控件的进度条与「快进 / 快退」操作不生效的问题已修复（`flutter_media_session`
  升到 3.2.1，上游修正了 MPRIS `Seek` / `SetPosition` 丢失目标位置）。

## 其它

- 依赖升级到最新：`flutter_media_session` 3.2.1、`material_3_expressive` 1.2.3 等，
  无界面改版。

## 升级说明

- 测试版与 0.2.1-beta.3 使用同一签名，可直接覆盖安装；构建号单调递增，
  应用内更新能正常识别。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
