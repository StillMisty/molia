# Molia 0.2.1-beta.3

0.2.1-beta.2 之后的第三个测试版。这一轮包含本地曲库增强、Linux 媒体会话统一，
以及一次覆盖全仓的架构重构。

## 本地曲库

- **Android 音乐文件夹支持 SAF**：通过系统文件选择器添加目录（如 SD 卡 / 云盘
  提供方），不需要广泛存储权限；支持树扫描、增量更新、播放与缓存 / 下载写入。
  原有绝对路径目录继续可用；位置无效与暂时读不到会分开提示。
- **本地歌曲缓存状态改用设备本地缓存索引**：只记录本机真正写完的音频缓存；
  收藏页「本地歌曲」的缓存行不再依赖启动扫描，新增 ⋮「核对本地缓存」手动补齐。
  缓存完成事件独立记录，切歌后完成的后台缓存也能计入。
- 数据库自动迁移到 v4（新增 `local_cache_index` 表），已有资料保留。

## 播放与系统

- Linux 系统媒体会话统一到 `flutter_media_session`（MPRIS），行为与其它平台一致。
- 系统低内存时先提交播放会话与听歌统计，减少进程被回收时丢失进度。
- Android lifecycle trim 与真实低内存分开处理，普通退后台不再误清浏览缓存。
- 顶栏换曲标题改为淡入淡出，消除新旧标题叠影。

## 稳定性与内部

- 全仓架构重构：领域模型 / 服务目录归一，组合根拆分为 `app/bootstrap/**`，
  收藏页 / 封面堆叠 / 歌词页 / 设置 / 统计 / 年度报告 / 应用壳拆分为更小的模块，
  并清空 UI → data 的存量白名单。用户可见行为不变，测试与架构守卫保持全绿。
- 升级 `file_picker` / `material_ui` 等顶层依赖。
- 修复同步未设置口令时的刷屏与无效重连、本地封面缺失时的取色报错、
  缓存索引清理时序等问题。

## 升级说明

- 测试版与 0.2.1-beta.2 使用同一签名，可直接覆盖安装；构建号单调递增，
  应用内更新能正常识别。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
