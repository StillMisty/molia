# Molia 0.4.1

0.4.0 之后的小版本：修正移动端播放页的返回层级，并统一桌面顶栏品牌区与
窗口按钮的留白。

## 修复

### 移动端播放页

- **返回层级按页内状态判定**：正常播放页（封面 + 控制、歌词在下方）按系统
  返回直接退出应用；歌词占满整页（播放器高度 0）时，第一次返回先恢复成正常
  播放页，第二次才退出。「歌词整页」不再被当成退出应用前的额外导航层级。
- 返回不会跨底栏 tab；页内手势、圆点与重复点击播放目的地切换歌词整页的行为
  不变。桌面 Esc 与页内展开 / 收起手势同样保持不变。

### 桌面

- **顶栏留白统一**：品牌胶囊距窗口左缘 / 顶部、窗口关闭键距顶部 / 右缘都统一
  为 8dp。品牌胶囊四边内边距一致，只有 LOGO 时是 40×40 正圆，与设置 / 窗口
  按钮的 24 图标 + 40 视觉格落在同一网格。

## 注意

- 与 0.4.0 使用同一签名，可直接覆盖安装。
