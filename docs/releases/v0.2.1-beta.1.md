# Molia 0.2.1-beta.1

0.2.0 之后的第一个测试版。这一轮集中在两处「分享」：年度报告和歌词海报。

## 改进

### 年度报告

- **布局按内容宽度分档**：报告页挂在设置弹层里，内容区通常比窗口窄；现在按实际可用
  宽度决定单列还是两栏，窄屏不再被挤成两列，宽屏的歌手 / 专辑榜单并排展示。
- 月份柱状图直接标出全年峰值；多个最高月份并列时不再强行挑一个。
- 统计只覆盖部分时段或已关闭时，这层说明从脚注提到正文，避免误读数字。
- 首次播放、最近播放和「保存为歌单」按宽度排布：窄屏整行按钮更好点，宽屏不压过顶栏
  的分享主操作。

### 年度报告海报

- 重新排版：年份主视觉、三张统计卡、月份柱状图、常听曲目与歌手 / 专辑榜单统一到一版
  设计稿；底部品牌水印在图标缺失时退回纯文字，不影响分享。
- 榜单按内容实际高度收拢到页脚上方，短内容不再留一大条空白，长歌名也不会压到水印。
- 海报只画歌名与歌手，不额外拉取封面：年度报告可能混合多个平台，分享图不应因此发起
  一批网络请求。

### 歌词海报

- 成品宽度与年度 / 听歌统计海报对齐，方便分享平台统一裁切；歌词过长时按比例缩小字号与
  行距，而不是裁掉内容，也不会触碰单张图片的高度上限。
- 换配色、换字体只重新排版绘制，封面直接复用已下载的字节；封面与水印并行准备，预览页
  不再为显示而反复编码 PNG。
- 排版只做一次，量高与绘制共用同一份结果，临时文本对象及时释放。
- 预览页连续切主题、拖动画时做防抖，同一时间只跑一轮渲染，旧图保留到新图完成。

### 歌词选择

- 底栏在窄屏或大字号下自动退化为两行：复制、全选 / 取消全选和海报入口不再被挤成
  省略号；复制按钮改成带图标的「复制」，不再把行数塞进按钮文字。

## 升级说明

- 测试版与 0.2.0 正式版使用同一签名，可直接覆盖安装；构建号单调递增，应用内更新能正常
  识别。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
