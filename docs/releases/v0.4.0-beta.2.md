# Molia 0.4.0-beta.2

0.4.0-beta.1 之后的测试版：主体是原生互操作层的重构与工具链升级（用户可见行为
不变），另修复了收藏页在更换封面 / 改名后一直停在加载状态的问题。

## 修复

- **改封面、改名后收藏页不再卡在加载中**：这类操作只写列表本身，却被当成整张列表
  失效，当前列表的曲目缓存被丢掉，收藏页随之退回加载状态。现在只刷新列表信息，
  曲目缓存保留；已删除列表的缓存会正常作废，不会被异步写回。
- 收藏页在后台静默刷新被跳过时不再因为空值崩溃。

## 改进

- **桌面包体积略减**：发布包不再携带运行期用不到的 JNI 运行时（Linux 实测约
  157 KB），发布前的体积守卫会拦住残留。

## 内部

- 原生互操作层（ADR-0038）落地：桌面 FFI 与 Android JNI 改为生成绑定；Android
  的系统文件选择器（SAF）、下载入库、下载通知、桌面小组件更新统一走 Pigeon
  类型化通道，失败仍回退旧通道。架构测试强制边界，CI 校验生成物漂移。
- 工具链升级：Flutter 与 Gradle 跟到 `AGENTS.md`「工具链」一行，jni / jni_flutter
  与 Android 桌面小组件加载封面用的 Glide 同步升到当前版本。

## 升级说明

- 测试版与 0.3.0 及各测试版使用同一签名，可直接覆盖安装；构建号单调递增，应用内
  更新能正常识别。设置 › 更新 › 更新渠道选「测试版」即可收到本版。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
