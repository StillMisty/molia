# Molia 0.2.1-beta.2

0.2.1-beta.1 之后的第二个测试版。这一轮主要是设置页收敛，另外带上收藏定位与
统计海报的排布修正。

## 设置

- **首屏精简**：桌面端从约 39 行降到约 28 行，下载设置 / 下载管理 / 缓存管理
  合并为「下载与缓存」，通知栏·锁屏与车机歌词并入「歌词与输出」。
- **新增「高级设置」**：应用字体、默认封面、淡入淡出、智能随机、加入位置、
  震动反馈、应用名称、窗口记忆、省流音质、下载模板 / 标签 / 通知、缓存保留
  策略与更新地址收进这里。字体与震动的自定义能力保留，只是不再占首屏。
- **桌面歌词减少一屏**：主页面只留开关、预览、字号、透明度、宽度、颜色与
  隐藏暂停；对齐、阴影、冻结、动画、暂停回退与控制条按钮进「高级」。
- **文案收敛**：删除重复标题与解释内部实现的副标题，只保留状态、后果、权限
  与不可逆提示。

## 其它

- 收藏页长按底栏 / 导航轨的收藏图标，可切到收藏页并定位当前播放曲目；
  找不到、未在播放或曲库浏览时给底栏提示，不退出搜索、多选与排序。
- 听歌统计分享海报重排，分享图的信息层级更清楚。
- 年度报告海报移除「截至今天」文案，年份入口更明确。

## 升级说明

- 测试版与 0.2.1-beta.1 使用同一签名，可直接覆盖安装；构建号单调递增，
  应用内更新能正常识别。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
