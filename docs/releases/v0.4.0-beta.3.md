# Molia 0.4.0-beta.3

0.4.0-beta.2 之后的测试版：重点是万级曲库下的浏览与统计页流畅度，同时收口了一批
窄屏布局、返回层级与设置交互问题。

## 改进

- **万级曲库浏览更少卡顿**：浏览索引不再在界面线程逐行解码曲目原始数据，改为用到时
  才解码；曲库超过 2000 行时索引构建放到后台 isolate。10k 行实测原本占界面线程
  22.7–33.1ms 的索引构建不再阻塞界面。
- **切收藏不再整库重读**：收藏 / 取消收藏只增量更新当前浏览索引，10k 收藏下仍在
  120Hz 帧预算内（`jank8=0`，p99 4.30ms）；批量、换源、同步与导入仍走整库校准。
- **统计页开页明显更顺**：两张热力图改为一整张网格批量绘制，开页 p99 从 126ms
  降到 42–53ms（约 −45%），最差帧 216 → 约 150ms；悬停提示、读屏逐格数值与
  离开后的 100ms 消失都保留。

## 修复

- 窄屏与交互审查一批收口：
  - 播放器：桌面窄窗有音量入口；350–399 宽迷你条标题不再被挤没；封面无障碍语义与
    侧邻光标正常；200% 字号下布局不再溢出。
  - 壳层：桌面底栏标题 / 进度改为 4:6 并给中区封顶；减弱动效时直达终态；离页停止
    动画；Android 返回键与桌面 Esc 按层级返回（含首次引导退回上一步）。
  - 搜索 / 曲库：Ctrl+F 落在歌手行可直接进歌手页；歌单详情宽度收口；搜索轮播与
    结果过渡更稳；歌单切换防抖、标签互斥。
  - 设置：窄窗口下分段行自动降级为下拉；条件行展开收起有过渡；危险操作统一错误色
    文案；下载与缓存设置合并为一页；收藏合集刷新时保留旧正文；360 宽下多选栏文字
    省略不再撑破。
  - 下载 / AI 推歌：从 AI 推歌历史点曲目即可起播；删除有确认、失败可重试；等待中
    的任务可取消，取消全部有确认；超过 20 条可展开。

## 内部

- 性能口径新增 `jank8`（work > 8.33ms）与两个 120Hz 桌面场景（10k 收藏切换、
  统计页开页）；`FrameStats` 从场景开始重新计时。
- 热力图语义改由 painter 的 `semanticsBuilder` 分帧输出，避免一次建 568 个节点
  造成 10–19ms 尖峰。
- 文档收敛：删除过时条目，生成物 / schema 版本 / 验证命令只保留单一权威位置。

## 升级说明

- 测试版与 0.3.0 及各测试版使用同一签名，可直接覆盖安装；构建号单调递增，应用内
  更新能正常识别。设置 › 更新 › 更新渠道选「测试版」即可收到本版。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
