# Molia 0.5.0-beta.1

0.5.0 的首个测试版，用于开启 0.5.0 测试通道。这一版功能与 0.4.1 相同。

## 与 0.4.1 相同

- **移动端播放页返回层级**：正常播放页（封面 + 控制、歌词在下方）按系统返回
  直接退出应用；歌词占满整页时，第一次返回先恢复成正常播放页，第二次才退出。
- **桌面顶栏留白**：品牌胶囊距窗口左缘 / 顶部、窗口关闭键距顶部 / 右缘均为
  8dp；品牌胶囊四边内边距一致，只有 LOGO 时是 40×40 正圆。

## 注意

- 测试版与稳定版使用同一签名，可直接覆盖安装。
- 测试版走滚动 `beta` 更新清单，会先于稳定版收到后续 0.5.0 的改动。
