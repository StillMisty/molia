# Molia 0.3.0

0.2.0 之后的稳定版本，汇总 0.2.1-beta.1 ~ beta.4 的全部内容：分享海报重新排版、
设置页收敛，本地曲库接入 Android 系统文件选择器并由设备本地缓存索引驱动，
Linux 系统媒体会话统一。

## 改进

### 分享海报

- **年度报告**：按实际可用宽度决定单列还是两栏，窄屏不再被挤成两列；月份柱状图
  直接标出全年峰值；统计只覆盖部分时段或已关闭时，说明从脚注提到正文；「保存为
  歌单」与分享按钮按宽度排布。
- **年度报告海报**：年份主视觉、统计卡、月份柱状图与榜单统一到一版设计；榜单按
  内容高度收拢，短内容不留空白、长歌名不压水印；海报只画歌名与歌手，不额外拉取
  封面。
- **歌词海报**：成品宽度与年度 / 听歌统计海报对齐；歌词过长时按比例缩小字号与
  行距而不是裁切；换配色、换字体只重新排版绘制，封面复用已下载的字节，预览不再
  反复编码 PNG；连续切主题时只跑一轮渲染。
- **歌词选择**：底栏在窄屏或大字号下自动退化为两行，复制改成带图标的「复制」，
  不再被挤成省略号。

### 设置

- 首屏精简：下载设置 / 下载管理 / 缓存管理合并为「下载与缓存」，通知栏·锁屏与
  车机歌词并入「歌词与输出」。
- 新增「高级设置」：应用字体、默认封面、淡入淡出、智能随机、加入位置、震动反馈、
  应用名称、窗口记忆、省流音质、下载模板 / 标签 / 通知、缓存保留策略与更新地址。
- 桌面歌词减少一屏：对齐、阴影、冻结、动画与暂停回退进「高级」。
- 文案收敛：只保留状态、后果、权限与不可逆提示。

### 本地曲库

- **Android 音乐文件夹支持系统文件选择器（SAF）**：可添加 SD 卡 / 云盘等目录，
  不需要广泛存储权限；支持树扫描、增量更新、播放与缓存 / 下载写入。原有绝对
  路径目录继续可用，位置无效与暂时读不到会分开提示。
- **本地歌曲缓存行改由设备本地缓存索引驱动**：只记录本机真正写完的音频缓存，
  不再依赖播放历史；缓存完成事件独立记录，切歌后才完成的后台缓存也会计入。
  收藏页「本地歌曲」合集 ⋮ 新增手动「核对本地缓存」：补齐完整缓存、清理已失效行。
- 数据库自动迁移到 v4（新增 `local_cache_index` 表），已有资料保留。

### 播放与系统

- **Linux 系统媒体会话统一到 `flutter_media_session`（MPRIS）**，行为与其它平台
  一致；系统媒体控件的进度条与快进 / 快退可用（该问题在 3.2.1 修复）。
- 系统低内存时先提交播放会话与听歌统计，减少进程被回收时丢失进度；Android
  lifecycle trim 与真实低内存分开处理，普通退后台不再误清浏览缓存。
- 收藏页长按底栏 / 导航轨的收藏图标，可切到收藏页并定位当前播放曲目。
- 顶栏换曲标题改为淡入淡出，消除新旧标题叠影。

## 修复

- **同一音频缓存文件只允许一个写入者**：重复播放、自动连播或播放失败原地重取时
  不再并行写同一份 `.part`，不再出现「完整文件 + 半成品」并存，也不会在先后完成
  时覆盖已经可用的缓存；完整缓存已在位时直接本地播放并清掉中断残留。
- 未设置同步口令时不再刷屏与无效重连。
- 本地封面文件缺失时跳过取色，不再报错。
- 封面缓存索引改为等索引仓库打开后再清理失效条目。
- 区分本地音乐文件夹「位置无效」与「暂时读不到」；预期取词失败不再按严重错误
  记录堆栈。

## 内部

- 全仓架构重构：领域模型 / 服务目录归一，组合根拆分为 `app/bootstrap/**`，收藏页 /
  封面堆叠 / 歌词页 / 设置 / 统计 / 年度报告 / 应用壳拆分为更小的模块，并清空
  UI → data 的存量白名单。用户可见行为不变，测试与架构守卫保持全绿。

## 升级说明

- 正式版与 0.2.0 及各测试版（0.2.1-beta.N）使用同一签名，可直接覆盖安装；构建号单调递增，
  应用内更新能正常识别。测试版用户升级到本版后走稳定渠道。
- 本项目仍处于快速迭代期，不承诺跨版本数据与协议兼容；需要保留的资料请先备份。
