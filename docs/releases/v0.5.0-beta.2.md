# Molia 0.5.0-beta.2

0.5.0 的第二个测试版，集中修复安卓桌面歌词的残留、叠字与窗口生命周期问题。

## 修复

### 桌面歌词

- **窗口跟随引擎释放**：退出应用或 Activity / Flutter 引擎重建后，旧的悬浮窗
  会随引擎一起销毁，不再留下最后一句旧歌词。悬浮窗改为进程级单窗口 owner，
  新引擎接管时先销毁旧窗口，从根上避免「上一句还在、下一句叠在上面」的双窗口
  叠字。
- **切行过渡改为确定性状态机**：滚入滚出只有一个显式句柄，任何内容 / 配置 /
  息屏 / 窗口销毁操作前都会同步收尾，旧句不会再因为动画回调丢失而永久留在
  视口里。重复副歌的相同文本也会按行身份正常换行。
- **空内容显式清空**：间奏空行、暂停回退「清空」、无歌词隐藏统一走显式清空，
  移除全部旧内容；空行期间不会把下一句误当成当前行。
- **权限自愈**：回前台时原生上报权限与窗口是否存在，权限撤销 / 重新授权后
  悬浮窗状态能自动校正并恢复显示。
- **暂停与设置切换**：Dart 侧改为串行状态机，暂停瞬间切换设置 / 主题不会再把
  本应隐藏的窗口带出来。

## 注意

- 测试版与稳定版使用同一签名，可直接覆盖安装。
- 测试版走滚动 `beta` 更新清单，会先于稳定版收到后续 0.5.0 的改动。
