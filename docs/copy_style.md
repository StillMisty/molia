# 文案规范（界面显示文案 + 黑话对照表）

> 适用范围：`lib/l10n/app_zh.arb`、`lib/l10n/app_en.arb` 以及一切用户可见文本
> （标题、副标题、按钮、提示、错误、空态、无障碍标签）。
> 先例提交：`git log --oneline -- lib/l10n/app_zh.arb` 最近的 `chore(l10n)` 一条。

## 1. 总则

- 面向用户，不是面向实现：只回答「能不能用」和「怎么办」，不解释应用怎么做的；
- 一条一个意思，副标题尽量一句话；能删的补充说明就删，删不掉的放对话框或日志；
- 实现细节一律不上面（API 路径、模块/协议名、内部状态词、性能术语、部署方式）；
- 中文短句优先，英文与中文同信息量（不逐字翻译，也不各写一套）；
- 产品词保留原有叫法，不为了「大众化」把全站术语改散（见 §4）。

## 2. 黑话 → 白话

| 黑话 | 说法 |
| --- | --- |
| 对端 / 候选地址 | 其它设备 / 可用地址 |
| 载荷 / 拉取 / 推送 | 数据 / 接收 / 上传 |
| 快照 | 同步数据 |
| 会话（内部义） | 状态（如「上次播放状态」） |
| 取链 | 播放链接（如「播放链接缓存」） |
| 探测端口 / 广播 / 组播 | 发现端口 / 自动发现 |
| 回环、link-local | 局域网地址 |
| 端点 / 绑定 | 连接端口 / 启动 |
| 前台服务 | 后台继续 |
| LRU 淘汰 | 自动清理最早的缓存 |
| 断点续传、直链、签名地址 | 从头重下；链接通常短期有效 |
| 孤儿文件 / 半成品（.part） | 残留文件 / 中断的临时文件 |
| 远端 / 远端存储 | 云端 / 云端文件 |
| 凭证 / 令牌 | 密钥 / 访问密码 |
| 绑定（快捷键） | 快捷键 |
| 注册（快捷键） | 生效 |
| 口径 / 主题角色 / 骨架实现 | 删除，改写成结果或怎么办 |
| 网段 / VPN / 防火墙（说明发现失败） | 删除，只留「自动发现失败时手动填写地址」 |
| 具体依赖名（AppIndicator、xdg-desktop-portal、Docker） | 删除或换成「托盘扩展」「桌面门户」 |
| JS 引擎、媒体元数据、API 路径 | 删除或换成「在本机运行」「系统播放控制」 |

## 3. 什么必须保留

- 不可逆操作的风险说明（删除、清理、重置、导入覆盖）与隐私同意书的事实要点；
- 用户需要照做的具体值：文件名模板变量、IP / 域名示例、端口范围、快捷键修饰键、Android 权限名；
- 同步失败原因的一句话结论（不含内部细节，细节在同步日志）；
- 面向脚本作者的免责声明：第三方脚本会联网运行、来源自负（去掉引擎实现细节）。

## 4. 保留的产品词

音源、渠道、脚本、音源脚本、歌词、桌面歌词、封面、歌单、列表、收藏、省流模式、
口令（同步信任根）、设备、同步、下载、缓存、取色、队列。

## 5. 长度与结构建议

- 设置项标题 ≤ 10 字，副标题 ≤ 24 字并尽量一行（设置页副标题 2 行封顶）；
- 开关类副标题只写「开/关之后发生什么」；开关和分段控件已经显示当前状态，不再重复默认值。
  确需提示默认值时放句尾：「（默认开启）」/「(on by default)」；
- 对话框：第一段说后果，第二段说用户要确认什么；不要重复标题；
- 空态：一句话说明现状 + 一句话给下一步，可用文案语气但不写实现。

## 6. 改文案的执行清单

1. zh / en 成对改，占位符 `{name}` 保持一致，不改 key（改 key 属于重构，另开提交）；
2. `flutter gen-l10n` 更新 `lib/l10n/app_localizations*.dart` 并一起提交；
3. 测试里的字面量断言按新文案同步更新（有 l10n 实例时优先引用 `l10n.<key>`）；
   `integration_test/` 用中文找控件的 finder 同步更新，并跑 `tool/agent/test.sh linux`；
4. `flutter analyze --no-pub` + `flutter test --no-pub` 全量过；
5. 批量文案改动保持一个 `chore(l10n): ...` 提交，与功能改动分开。
