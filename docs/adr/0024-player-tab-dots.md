# ADR-0024：播放页三个圆点保留紧凑命中区与激活圆点展开/收起

状态：已采纳（2026-11-14）。相关：`lib/widgets/mdtab.dart`、
`lib/pages/nowplaying.dart`、`lib/widgets/player.dart`、
`docs/architecture.md` §6。

## 背景

UI 收敛审计建议把播放页右侧的三个页指示圆点扩到 48dp 命中区，并删除
「点已激活圆点 = 展开/收起」的双义，理由是命中区小于 M3E 的 48dp 通用指引，
且一个控件承担了两种含义。

## 决策

**保留现状。** 三个圆点继续使用紧凑的 36×28 视觉/命中区，并保留
「点已激活圆点展开/收起」的手势：

- 不扩大不可见 padding；不改圆点尺寸与间距。
- 不删除激活圆点的展开/收起语义；展开/收起仍可由拖拽/下拉完成。
- 语义标签保留，供屏幕阅读器识别页签与当前页。

## 理由

- **视觉**：圆点是封面/歌词版式的一部分，扩到 48dp 会在视觉上引入一圈空白，
  挤压封面与歌词的呼吸感；当前尺寸是刻意打磨的结果。
- **人体工学**：圆点位于拇指自然落点附近，激活圆点再点一次展开/收起是高频、
  低成本的捷径；把它拆成两个控件反而增加操作。
- **例外边界**：这是播放页版式的刻意例外，不推广到其它页面；新页面仍按
  48dp 通用指引设计。

## 后果

- 圆点命中区低于 48dp 通用指引，作为已记录的例外存在；不因此重做播放页。
- 若未来重做播放页版式，需同时评估圆点尺寸、命中区、展开/收起手势与
  200% 字号；不允许只改其中一项。
- 审计中的「扩 48dp / 删双义」不再进入收敛清单。
