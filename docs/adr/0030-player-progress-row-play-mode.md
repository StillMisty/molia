# ADR-0030：播放页进度排常显播放模式（撤回「更多」菜单）

状态：已采纳（2026-11-15）。相关：ADR-0007（播放域划分）、
ADR-0023（其中「进度排用『更多』收纳模式」一条被本 ADR 取代）、
`lib/widgets/player.dart`、`lib/app/desktop/now_playing_bar.dart`、
`lib/widgets/playback_transport.dart`、`docs/architecture.md` §6。

## 背景

ADR-0023 定下「展开播放页不新增常显传输排」的同时，把播放模式从进度排右端
撤走，与「存为列表 / 歌词显示设置」合并成一个「更多」菜单。落地后发现三个问题：

1. **高频动作变两级菜单**：模式是播放域状态（ADR-0007 把播放域定在播放页），
   却要「更多 → 子菜单 → 选项」三次命中；当前模式只在子菜单里可见。
2. **一个菜单混了三个域**：播放模式（播放域）、存为列表（队列域）、歌词显示
   设置（歌词域）挤进同一个入口。队列页顶部入口被删后，「存为列表」只能挂在
   播放页。
3. **会话状态不再可见**：进度排右侧从模式图标变成 ⋮ 后，列表循环 / 单曲循环 /
   随机播放只能点开菜单才知道。

## 决策

1. **进度排右端常显播放模式按钮**：收藏 + 可拖动进度 + 模式三件；点按按
   `PlayMode.next` 循环，图标与语义标签走 `PlayModeTransportPresentation`，
   不弹菜单。
2. **撤回「更多」菜单**：进度排不再有 ⋮。
3. **桌面底栏右区同样常显模式按钮**（播放模式 + 音量 + 队列），与播放页共用
   `PlaybackModeButton`。
4. **移除「存为列表」功能**：队列面板不再有顶部溢出菜单；批量建列表的编排、
   l10n 与测试一并删除，需要整队列时改为逐曲「加入列表」。
5. **歌词显示设置只留歌词页 FAB 入口**：播放页不再重复承载歌词域动作。
6. 迷你条、非播放页顶栏不增加模式按钮（ADR-0023 的其余结论不变）。

## 理由

- **归属**：模式是播放域状态，播放页进度排是它的主场景；队列域 / 歌词域动作
  回到各自的域（ADR-0007）。
- **成本**：模式切换从两次展开（更多 → 子菜单）回到一次命中，当前模式一眼可见。
- **宽度代价可接受**：右侧固定 44dp，进度条仍拿到「收藏」与按钮之间的整段
  可拖宽度；播放页不是表格页，隐藏状态比 44dp 更贵。
- **删功能而不是搬家**：唯一入口撤回后，存为列表要在队列页或进度排再占一个
  常驻入口；低频动作不值得，逐曲加入列表已覆盖需求。

## 后果

- 进度排固定三件（收藏 / 进度 / 模式），进度条实际宽度比「更多」版式略窄；
  这是刻意取舍，不再以「进度条更宽」为由撤掉模式按钮。
- 桌面底栏右区多一个按钮，中区进度排相应变窄。
- 「存为列表」从产品中消失，发布说明要写清替代路径（逐曲加入列表）。
- 失效的 l10n 键（`queueSaveAsPlaylist` / `queuePlaylistDefaultName` /
  `queueSavedAsPlaylist` / `queueSaveFailed` / `playModeTitle`）随功能一并删除。
- 未来重做进度排必须同时评估三件控件、封面主操作与 200% 字号；不要再把模式
  藏进菜单。
