# ADR-0033：设置二级收敛——首屏 ≤30 行与统一高级出口

- 状态：已采纳
- 日期：2026-11-16
- 相关：`lib/pages/settings_page.dart`、`lib/pages/settings_advanced_page.dart`、
  `lib/pages/downloads_and_cache_page.dart`、`lib/pages/lyrics_display/`、
  `docs/architecture.md` §6、`test/widgets/settings_page_test.dart`

## 背景

ADR-0027 把首屏按域分成 9 张卡后，桌面首屏仍有约 40 行。继续按「再加一行」
增长会出现三个问题：

- 实现级旋钮直接暴露：更新清单 / 镜像前缀、缓存歌词 TTL / 封面数量与过期、
  下载文件名模板 / 标签嵌入 / 通知、桌面歌词 6 个控制条按钮开关；
- 同一件事拆成多个入口：下载设置 / 下载管理 / 缓存管理占三行，桌面歌词 /
  歌词与输出 / 系统媒体歌词占三行，采集开关与统计入口占两行；
- 副标题在解释应用怎么做的，而不是用户需要知道什么。

## 决策

1. **首屏目标 ≤30 行**，一级仍是 ADR-0027 的 9 张语义卡，不新增目录页。
2. **新增唯一「高级设置」出口**（首屏「关于与更新」卡末行），集中收纳
   「还在、但很少改」的选项：应用字体、默认封面、淡入淡出、智能随机、加入
   位置、震动反馈、应用名称、窗口记忆、省流音质上限、下载模板 / 标签 / 通知、
   缓存保留策略、更新信息地址与下载镜像。
3. **同域合并**：下载设置、下载管理、缓存管理合并为「下载与缓存」子页
   （任务队列仍由 `DownloadsManagePage` 承担，本页只留入口）；通知·锁屏与
   车机歌词并入「歌词与输出」，输出细节进该页的「高级」。
4. **歌词域保留两个局部高级页**：系统媒体歌词高级（目标 / 格式 / 翻译 /
   暂停 / 更新间隔）与桌面歌词高级（对齐 / 阴影 / 冻结 / 动画 / 暂停回退 /
   无歌词行为 / 控制条按钮）。它们依赖预览与输出上下文，不放进全局高级页。
5. **保留自定义能力**：字体与震动不删除，只从首屏移到高级设置；底层设置键、
   默认值与同步类别不变，不需要数据迁移。
6. **文案只写状态、后果、权限与不可逆提示**：删除重复标题、解释内部事件、
   频率与实现细节的副标题；设置项标题 ≤10 字，副标题 ≤24 字并尽量一行。

## 后果

- 首屏约 40 → 28 行，下载 / 缓存 / 歌词 / 桌面歌词子页各减少一半左右；
  高级页约 17 行，只在需要时进入。
- 下载与缓存的设置、任务、清理共享同一页，少两次跳转；统计采集开关回到
  统计页，与数据本身同屏。
- 新增 `settings_advanced_page.dart`、`downloads_and_cache_page.dart`、
  `lyrics_display/desktop_lyrics_advanced_page.dart`、`lyric_color_row.dart`、
  `widgets/settings/cache_policy_dialog.dart`；删除 `download_settings_page.dart`
  与 `cache_management_page.dart`，系统媒体歌词页改为高级页。
- 若将来还要压缩首屏，优先把新项放进现有高级页或对应子页，不再往首屏加行；
  重新引入一级目录页需要新的 ADR 与真实使用证据。
